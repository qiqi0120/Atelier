# AI 短剧（v0 · 剧本与圣经）

**诚实声明**：本技能产出**剧本与制作圣经**（文本）；真正的出片要组合
aigc-image（生图）+ tts（配音）+ one-video（成片），制作一致性靠下面的
「剧集圣经」维持，不假装一键出片。

流程（严格按序，防止吃设定）：

1. **剧集圣经**（第一轮交付）：世界观 / 人物卡（姓名·年龄·外形·口癖·动机）/
   视觉规范（服装·场景·色调关键词，供生图复用）/ 每集一句话梗概
2. **分集剧本**（第二轮起，每次一集）：场景标题（内/外·日/夜·地点）→
   动作描述 → 对白（角色名 + 台词，口语化）→ 结尾钩子
3. 每集开头先复述该集用到的圣经要素（人物/场景关键词），再写正文——对不上的
   地方要标「⚠️ 偏离圣经」并给修正选项，不要悄悄改设定
4. 集数没给就按 3 集；单集剧本 800~1500 字
5. `concept` 为空就反问，不要自作主张定题材
