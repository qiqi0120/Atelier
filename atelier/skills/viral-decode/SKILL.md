# 爆款拆解

固定 **6 段式**输出，保证每条拆解都能横向对比。
**只拆结构，不抄内容** —— 抄结构可以，抄原文是偷。

## 6 段式（不许增删改顺序）

1. **原帖事实** — 逐条列出原文里**客观存在**的东西（标题、开头、篇幅、话题、发布时间），不许加评价
2. **爆点定位** — 它到底哪一句/哪一段让人停下来；给出原句摘录
3. **结构拆解** — 用可复用的骨架描述（如「反常识结论 → 3 个证据 → 行动指令」）
4. **情绪曲线** — 读者从第 1 秒到读完的心路（好奇 / 认同 / 焦虑 / 行动）
5. **可复用公式** — 写成 `当 ⟨情况⟩ 时，⟨结论⟩ + ⟨证据⟩ + ⟨行动⟩` 的填空模板
6. **我的改写建议** — 结合 `goal` 给出 1 条具体可执行建议（不是 3 条泛泛而谈）

## 执行

```bash
python atelier/skills/viral-decode/run.py \
  --params '{"text":"…","metrics":"赞 3.2w 藏 1.1w 评 876","goal":"涨粉"}' \
  --out outputs/<项目>/成品/viral-decode
```

脚本负责**第 1 段的事实抽取**（确定性，不许编）和**第 2 段的原句定位**，
第 3–6 段由 agent 基于事实撰写 —— 脚本不生成观点，避免编造。

## 门禁要求

- `compliance`（BLOCK）：拆解里引用原帖，**不得**出现极限词背书
- `ai_flavor`（WARN）：第 6 段建议若是「多发内容就好」这类空话，告警
- 特别注意：**不得输出「照抄这段原文」的建议**

## 落盘

- 路径：`<项目>/成品/viral-decode/<slug>.md`
- 文件严格 6 个 `##` 段，缺任一段视为失败

## 失败处理

| 情况 | 处理 |
|---|---|
| 原文 < 40 字 | 拆不动，回问要完整文案或截图文字 |
| `metrics` 为空 | 照常拆，但第 1 段必须写「未提供数据，不做效果归因」 |
| 无法定位爆点 | **如实说「未能定位」**，不许硬编一个爆点 |
