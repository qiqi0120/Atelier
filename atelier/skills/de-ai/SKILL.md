# 去 AI 感改写

把「模型味」文本改成「人写的」：砍填充语、打破三段等长、变主动语态、长短句交替。
输出**改前 / 改后 / 五维打分对比**。

## 何时用

用户已有草稿或模型初稿，觉得「太顺、太满、太套路」。
不要用本技能去做**第一次创作**（那用 `social-copy`）；本技能只做「已经能看 → 更好看」。

## 执行

优先跑确定性脚本（`strength` = `light` / `medium` / `strong`）：

```bash
python atelier/skills/de-ai/run.py \
  --params '{"text":"…","platform":"xhs","strength":"medium"}' \
  --out outputs/<项目>/成品/de-ai
```

脚本做四件事：

1. **砍填充语**：命中黑名单的短语整段删除（`众所周知` / `在这个快节奏的时代` / `总而言之` /
   `值得注意的是` / `让我们一起` / `不仅仅是…更是` / `赋能` / `闭环` / `颗粒度` / `对齐`）
2. **破等长结构**：若三段字数极差 < 15%，重排段序并把最长段拆句
3. **主动语态**：`被…所` / `进行了` / `有一个…` 改写为主动句式
4. **长短交替**：强制相邻句长差不小于 6 字，连续三句同长则拆/并

## 五维打分（脚本输出，启发式，非权威）

| 维度 | 看什么 |
|---|---|
| 直接性 | 开头是否直接给结论，有无「铺垫句」 |
| 节奏 | 句长方差 + 长短交替度 |
| 信任度 | 有无具体数字/时间/第一人称经历 |
| 活人感 | 填充语残留、口语标记、标点个性 |
| 精炼度 | 压缩率 + 单句平均字数 |

分数是**可复现的启发式指标**，用来对比改前改后，不是「AI 检测器」结论。
对外不要宣称「过了 AI 检测」——本技能不承诺这一点。

## 门禁要求

- `ai_flavor`（WARN）：改后仍低于阈值 → 告知用户「仍偏模板腔」，给具体改法，不要假装已解决
- `compliance`（BLOCK）：改写**不得**引入极限词或新承诺；删减只能减，不能加
- `secret_scan`（BLOCK）：原文若含密钥必须阻断，不许靠改写绕过

## 落盘

- 路径：`<项目>/成品/de-ai/<标题slug>-deai.md`
- 文件结构：`## 改前` / `## 改后` / `## 五维对比`（表格）/ `## 改了哪些`（逐条说明）
- 在对话里同时把「改后」正文贴出来，用户要能一眼看到结果

## 失败处理

| 情况 | 处理 |
|---|---|
| 原文 < 30 字 | 不改写，回问是否要重写（那是 `social-copy` 的活） |
| `strength=strong` 仍残留填充语 | 记 WARNING 并列出残留词，让用户决定 |
| 改写丢失数字/专名 | **回滚**该条：`keep_facts=true` 时事实丢失视为失败 |
