# 论文解读

论文文本 → 结构化解读。规则：

1. **恰好 6 段**（`##` 标题）：`一句话总结` / `要解决的问题` / `方法拆解` /
   `关键结果` / `局限性` / `对我们有用什么`
2. 只解读文本里有的内容：数字、结论、方法名都要能在原文找到；拿不准就写
   「原文未明确」，**不脑补实验细节**
3. `关键结果` 里的数字原样引用（单位带上）；`局限性` 至少 2 条（原文自述 +
   你的判断分列）；`对我们有用什么` 结合 angle 给 1~3 条可落地动作
4. 文本太短（<500 字）或像摘要片段就先说明解读会受限，再尽量输出
5. 没给文本就反问，并提示用 pdf-extract 技能抽取
