# Atelier UI 设计规范 v1（实现依据）

> 配套原型：`design/prototype-v1.html`（13 个页面，单文件可交互）
> 本文件是前端实现时的**唯一视觉依据**，避免实现阶段各写各的。

---

## 1. 设计定位

**简约清爽 = 减法，不是简陋。**

| 原则 | 具体要求 |
|---|---|
| 一屏一件事 | 每个页面只有一个主行动按钮（primary），其余降级为 ghost |
| 密度偏紧 | CJK 页面：正文 14px、行高 1.55、卡片内边距 16px、区块间距 16–20px |
| 留白靠减元素 | 不靠加大间距撑场面；宁可少一个卡片 |
| 状态可见 | 成熟度 / 门禁 / 登录态 / 缓存时间必须显式标注，不靠猜 |
| 破坏性操作有摩擦 | 删除、发布、登出必须二次确认，且文案说清后果 |

## 2. 设计令牌（Design Tokens）

### 2.1 颜色

```
背景        --bg          #fafaf9   页面底色（暖白，非纯白）
卡片        --surface     #ffffff
次级面      --surface-2   #f6f5f3   看板列、输入框底
三级面      --surface-3   #efeeeb   进度槽、骨架

描边        --line        #e7e5e3   卡片边
弱描边      --line-soft   #f0efed   卡内分隔线

文字        --ink         #1c1917   标题
            --ink-2       #57534e   正文
            --ink-3       #78716c   次要说明
            --muted       #a8a29e   占位符/极次要

主色        --accent      #10b981   唯一强调色（绿）
            --accent-ink  #047857   主色上的文字
            --accent-soft rgba(16,185,129,.10)  主色 10% 底
            --accent-line rgba(16,185,129,.28)  主色边框

语义（仅用于状态，不做装饰）
警告        --warn        #f59e0b / 底 #f59e0b12
危险        --danger      #f43f5e / 底 #f43f5e17
信息        --info        #3b82f6 / 底 #3b82f908
```

**规则**
- 页面只有一个主色，语义色只出现在「状态标识」上，不得当装饰用
- 禁止纯黑 `#000`、禁止紫蓝渐变、禁止霓虹发光
- 主色填充用 5–10% 透明度做大面积底，100% 只用于小面积按钮/图标

### 2.2 字体

| 用途 | 字体 | 回退 |
|---|---|---|
| 拉丁 / 数字 | `Outfit` 400/500/600/700 | — |
| 中文 | PingFang SC / Hiragino Sans GB / 微软雅黑 | — |
| 代码 / 路径 / 数字读数 | `JetBrains Mono` 400/500 | ui-monospace |

`font-family: 'Outfit', 'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei', sans-serif`

**字号阶梯**
```
H1 页面标题   21px / 600 / -0.015em
H2 区块标题   14px / 600
小标签 lbl    11px / 600 / +0.05em / 大写
正文          14px / 1.55
次要说明      12.5px
辅助 help     11.5px
数字读数      23px / 600 / mono
```

### 2.3 圆角 / 阴影

```
圆角  卡片 14px · 控件 10px · 标签/输入 7px
阴影  基础 0 1px 2px rgba(0,0,0,.04), 0 4px 14px -4px rgba(0,0,0,.06)
      悬浮 0 6px 20px -6px rgba(0,0,0,.16)
      浮层 0 8px 32px -8px rgba(0,0,0,.14)
```
**禁止**：重投影、彩色阴影、`border-l-4` 色条卡片。

## 3. 布局骨架

```
┌──────────┬────────────────────────────────────────┐
│ 侧边栏    │ 顶栏 56px（面包屑 / 视图切换 / 体检 / 新会话）│
│ 236px    ├────────────────────────────────────────┤
│ 品牌      │ 视图区（各页独立滚动）                    │
│ 导航分组   │  · 普通页：max-width 1180 居中 + 24px 内边距│
│ 画像切换   │  · 对话页：全宽分栏（会话 216 + 主区）      │
└──────────┴────────────────────────────────────────┘
```

- 侧边栏分组：`工作台` / `输入`（热点、能力地图）/ `策划` / `发布` / `系统`
- 侧边栏底部常驻**画像切换器**（头像 + 账号名 + 平台 + 生效状态点）
- ≤900px：侧边栏收成 60px 图标栏；对话页隐藏会话栏；卡片网格降为 1–2 列
- ≤768px：日历格降高 64px，事件字号 10px，**不得出现横向滚动**

## 4. 组件规范

| 组件 | 规格 |
|---|---|
| 主按钮 | 32px 高，`--accent` 填充，白字，阴影 `0 1px 6px rgba(16,185,129,.25)` |
| 次按钮 | 32px，白底 + `--line` 边，hover 上浮 0.5px |
| Ghost 按钮 | 无边框，hover 显示 `--surface-2` 底 |
| 危险按钮 | `--danger-ink` 字 + 30% 红边，hover 红底 |
| 禁用按钮 | 45% 透明，**必须配 tooltip 说明原因**（如「缺 MINIMAX_API_KEY」） |
| Chip | 22px 高，20px 圆角；变体 `.a/.w/.d/.i/.o/.on`；mono 变体用于 ID/路径 |
| 标签页 | 容器 `--surface-2`，选中项白底 + 微阴影 |
| 状态点 | 6px 圆点；绿=有效，琥珀=即将过期，红=失效 |
| Toast | 右下角，2800ms 自动消失，深色底，成功绿/警告琥珀 |
| 抽屉 | 右侧 560px，`transform` 260ms 弹出，带遮罩 |
| 模态 | 居中 520px，缩放+淡入 220ms |
| 空态 | 居中，标题 14px + 说明 12.5px（max-width 320px），**必须给出下一步动作** |

## 7. 实现约束（给前端）

1. **禁止引入重型 UI 框架**（Ant Design / MUI / Chakra）。用原生 CSS + CSS 变量实现上述令牌，理由：控制体积与视觉一致性，避免主题覆盖冲突。
2. **图标用 lucide-react 内联 SVG**，`stroke-width="1.9"`，`currentColor`。禁止用 emoji 当图标。
3. **Markdown 渲染**用 `react-markdown` + `remark-gfm`；HTML 预览必须包在 `sandbox` iframe 里。
4. **字体**通过 Google Fonts 引入，失败时回退 PingFang SC，不阻塞首屏。
5. 长任务走 SSE，**不得用 tail 文件 + 轮询**（参考实现的已知技术债）。
6. 破坏性接口一律走确认弹窗组件，不允许在按钮上直接调。
7. 所有列表渲染走虚拟滚动（内容库 / 日历 / 评论）。
